# Siklus Air 3D — Simulasi Alam

Website edukasi interaktif siklus air menggunakan HTML, CSS, JavaScript, dan Three.js.

## Upload ke GitHub Pages
1. Buat repository baru, misalnya `siklus-air-3d`.
2. Ekstrak ZIP ini.
3. Upload **isi folder** (index.html, style.css, script.js, README.md) ke root repository.
4. Buka **Settings → Pages**.
5. Pada **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
7. Tunggu deployment selesai, lalu buka URL GitHub Pages yang muncul.

Website memerlukan koneksi internet untuk memuat Three.js dari jsDelivr dan Google Fonts. Pengunjung dapat memutar sudut pandang dengan mouse/touch, zoom, memilih tahapan, jeda, mengulang, dan mengatur kecepatan.
